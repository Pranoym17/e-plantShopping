# Paradise Nursery

Paradise Nursery is a React and Redux shopping application for browsing houseplants, adding plants to a cart, and adjusting cart quantities before checkout.

## Features

- Landing page with company name, background image, company description, and Get Started button.
- Product listing page with categorized houseplants, thumbnails, names, prices, and Add to Cart buttons.
- Shared header on product and cart pages with Home, Plants, and Cart navigation.
- Dynamic cart icon quantity powered by Redux state.
- Shopping cart page with total plant count, total cart amount, per-item totals, quantity controls, delete buttons, continue shopping, and checkout message.
